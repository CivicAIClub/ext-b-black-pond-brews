## What this is

This project builds marketing and email automation tools for Black Pond Brews, a brewery in Danielson, Connecticut. It is built by student developers in the Civic AI Club at Pomfret School for Black Pond Brews LLC. Status: discovery complete; Phase 1 not yet chosen.

## Client details

Discovery notes, contacts, and client requirements live in the club's private running doc (link in the Civic AI Club Google Drive). Do not copy them into this repo.

## Working on this repo

- **Client data never goes in git.** Sales PDFs, exports, spreadsheets, customer lists, and email lists stay in the gitignored `data/` folder or in Drive. This repository is public. See [data/README.md](data/README.md).
- Branch from `main` as `feature/<short-description>`, `fix/<short-description>`, or `chore/<short-description>` (lowercase, hyphens).
- Every change goes through a pull request with at least one approval. `main` cannot be pushed to directly.
- Cursor rules for this project are committed in `.cursor/rules/`. You do not need to paste anything into your IDE settings.
- The full Git walkthrough for beginners is the club's **[Developer Onboarding Guide](https://github.com/CivicAIClub/docs/blob/main/developer-onboarding.md)**.
